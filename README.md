# Onchain Notes

An Intelligent Contract deployed on GenLayer Testnet Asimov.

## What it does
- `add_note(text)` — saves a note onchain
- `get_notes()` — returns all saved notes
- `delete_last_note()` — removes the last note
- `get_count()` — returns total number of notes

## Tech Stack
- Python
- GenLayer SDK
- Testnet Asimov

## Use Case
Decentralized onchain notepad. Your notes are stored permanently on the blockchain — no servers, no censorship.
